# Rust/GTK4 Migration Implementation Plan

> **For agentic workers:** Use the parallel-agent skill for the independent,
> exclusively owned modules below. Integrate and review before cutover.

**Goal:** Replace the Python app with Rust/GTK4, prove compatibility, then
replace the application-owned C worker with Rust.

**Architecture:** Keep the existing modules and process protocol. Rust owns
the UI, recording, subprocess lifecycles, setup, configuration, and cleanup.
The existing C worker remains in place until the main migration passes.

**Tech stack:** Rust 2024, gtk4-rs 0.11, GTK4 layer-shell, GLib/GIO, Serde/TOML,
the pinned sherpa-onnx runtime, PipeWire, bubblewrap, wl-clipboard, and wtype.

**Spec:** `docs/superpowers/specs/2026-11-21-rust-gtk4-design.md`.

## Global constraints

- Preserve application ID `dev.hype.Flow`, status type `(ssddb)`, actions,
  private flags, XDG paths, settings, model assets, and all five settings pages.
- Keep PCM16 at 16000 Hz, maximum 300 seconds, and borrowed segmentation slices.
- Keep transcript/hotword files private and stale generations unable to paste.
- No model/runtime version change. Phase 2 cannot start before phase 1 passes.
- Keep the existing Python tree untouched as oracle and rollback source.
- No repository history exists. Work on `migrate/rust-gtk4`, retain a private
  source snapshot, and do not stage the owner's untracked tree wholesale.
- Dependency/build installation and reversible local validation are authorized
  by the owner's instruction to proceed. No further execution-method question.

## Review focus

1. Late capture/inference callbacks must not affect a later recording.
2. Cancellation must interrupt blocked worker input/output and reap children.
3. Unicode case folding and punctuation boundaries must match Python cleanup.
4. A changed clipboard or closed target must never receive stale paste/restore.
5. Failed download/installation must leave a usable model and runtime.

## Shared interfaces

All fallible functions use `anyhow::Result`. `Config` is a cloneable,
serializable struct whose public field names/types mirror current settings.
Paths in settings are `String`. CPU threads and unload minutes are integers;
scores/tolerances are `f64`. Constants keep their existing values.

- `Config::load() -> Result<Config>`, `validate(&self) -> Result<()>`,
  `save(&self) -> Result<()>`; `config::{data_dir,config_dir}() -> PathBuf`,
  `runtime_dir() -> Result<PathBuf>`.
- `cleanup::process(text: &str, values: &Config) -> Result<String>`.
- `vocabulary::{terms,hotwords}(text: &str) -> Result<Vec<String>/String>`;
  `sentencepiece_vocabulary(data: &[u8], tokens: &Path) -> Result<String>`.
- `segments::split_at_pauses(pcm: &[u8]) -> Vec<&[u8]>`.
- `Engine::new(config: Config, runtime: PathBuf) -> Engine`;
  `prepare(&self)`, `ensure(&self) -> Result<()>`,
  `transcribe(&self, pcm: &[u8]) -> Result<String>`, `stop(&self)`.
- `audio::Recorder::start(target: &str, hold: bool, on_frame: impl
  Fn(f64,f64)+Send+Sync+'static, on_end: impl Fn()+Send+Sync+'static)
  -> Result<Recorder>`; `stop(self) -> Result<Vec<u8>>`;
  `audio::release()`; `audio::sources() -> Vec<(String,String)>`.
- `process::run_command(command: &mut Command, input: Option<&[u8]>,
  timeout: Duration) -> Result<Output>`; enforce deadlines and bounded output.
- `output::focused_window() -> Option<serde_json::Value>`;
  `copy_text(text: &str, primary: bool) -> Result<()>`;
  `deliver(text: &str, target: Option<&Value>, paste: bool,
  trailing_space: bool, press_enter: bool) -> Result<String>`.
- `feedback::MediaPause::default()`, `pause(&mut self)`, `resume(&mut self)`;
  `feedback::play_cue(name: &str, runtime: &Path) -> Result<()>`.
- `hook::run_hook(text: &str) -> (String, Option<String>)`;
  `hook::hook_path() -> PathBuf`; `shortcuts::install() -> Result<String>`.
- `setup::assets_ready(&Config) -> bool`;
  `setup::install(progress: impl Fn(&str)) -> Result<(String,String)>`.
